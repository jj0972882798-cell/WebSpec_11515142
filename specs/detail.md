## 2. 技術邊界與架構規格

1. **純原生技術實現**：
   - 全站採用 HTML5 語意標籤、原生 CSS3（現代變數、Flexbox、CSS Grid、Clamp 流體字級）與原生 JavaScript (ES6+)。
   - 不依賴 React、Vue 等前端框架，不需 Webpack/Vite 建置打包流程，隨開即跑。
2. **零外部圖像損毀風險 (Zero External Image Dependency)**：
   - 全站吉他主視覺、商品圖示、音響木箱皆由純向量 SVG 搭配 CSS 漸層立體光影繪製而成，保證任何螢幕解析度下清晰銳利且 100% 離線可用。
3. **Web Audio API 物理諧波音色合成**：
   - 內建瀏覽器原生音訊合成引擎，透過 `AudioContext`、多重振盪器（Oscillators）、雙二階濾波器（BiquadFilter）與 ADSR 包絡線，即時演算吉他撥弦泛音，無需下載龐大 MP3/WAV 外部音檔。
4. **外部依賴庫 (CDN)**：
   - **Google Fonts**：`Montserrat` (400/600/700/800)、`Noto Sans TC` (400/500/700)、`Noto Serif TC` (600/700/900)。
   - **Font Awesome 6.4.0**：提供直觀專業圖標支援。

## 6. JavaScript 核心邏輯與演算法規格

### 6.1 購物車資料架構與狀態管理 (Cart System)

```javascript
// 購物車資料陣列結構
let cart = [
  { id: 1, name: "皇家深藍・旗艦全單民謠吉他", price: 98800, quantity: 1 }
];
```

- **核心函式規格**：
  - `toggleCart(show: boolean)`：控制購物車側邊抽屜（`.cart-drawer`）與背景遮罩（`.cart-drawer-overlay`）之開合。
  - `addToCart(id, name, price)`：檢查是否已存在品項，若已存在則累加數量；若不存在則 push 新物件。更新後呼叫 `updateCartUI()` 並展示 Toast。
  - `removeFromCart(id)`：透過 `filter` 移除指定項目並重繪畫面。
  - `updateCartUI()`：更新購物車徽章計數（`cartCount`）、累加總價（`cartTotal`），並依據清單是否為空動態渲染商品項目或空狀態圖文。
  - `checkout()`：檢查清單，執行結帳引導與防呆提示。

### 6.2 Web Audio API 物理諧波合成引擎 (Tone Studio Engine)

#### 和弦音高設定 (E minor 9)
```javascript
// 物理頻率 (Hz)：E2, B2, E3, G3, D4, F#4
const frets = [82.41, 123.47, 164.81, 196.00, 293.66, 369.99];
```

#### 掃弦與音色濾波演算法
- **掃弦時間差**：每根琴弦設定 `idx * 0.065s` 的時間位移，模擬真實手指由粗弦至細弦撥動的微小時間差。
- **音色參數對應表**：

| 音色類型 | 振盪器波形 (`osc.type`) | 濾波器類型 (`filter.type`) | 截止頻率 (`frequency`) 與行為 |
| :--- | :--- | :--- | :--- |
| **Acoustic (民謠)** | `triangle` | `lowpass` | 由 3200Hz 指數衰減至 300Hz（模擬木箱箱體吸音） |
| **Electric (電吉他)** | `sawtooth` | `bandpass` | 固定 1400Hz，Q 值設為 3.5（模擬磁性拾音器中頻穿透力） |
| **Classical (古典琴)** | `sine` | `lowpass` | 由 1800Hz 衰減至 150Hz（模擬尼龍弦圓潤無金屬雜音特性） |
| **Jazz (爵士拱頂)** | `triangle` | `lowpass` | 固定 900Hz（模擬溫暖雙線圈拾音器與厚重木板回音） |

- **ADSR 音量包絡線**：
  - Attack：`0.015s` 迅速爬升至 `0.35` 增益（撥片或指甲觸弦瞬間）。
  - Decay / Release：依據各音色持續時間（`durationSec = 2.5s`）以 `exponentialRampToValueAtTime` 平滑指數衰減至 `0.0001`。
